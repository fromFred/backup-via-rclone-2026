What this is

This page is the application home page for a personal rclone OAuth client. The client exists so that its owner can back up their own Google Drive to storage they control, using rclone from their own computer.

What it does

  • Reads files and metadata from the owner's Google Drive.
  • Copies them to a local disk or another storage location owned by the same person.
  • Runs only when the owner starts it manually (or via a scheduled job on their machine).

What it is not

  • It is not available to anyone other than the owner.
  • It has no server, no database, and no user accounts.
  • It does not sell, share, or analyse anyone's data.

Why this page exists

Google requires every OAuth application — even a private, single-user one — to publish a home page and a privacy policy before the app can be used with a personal client_id. This site fulfils that requirement, following the rclone documentation.
