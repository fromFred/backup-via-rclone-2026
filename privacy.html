Scope

This policy covers the personal rclone OAuth client described on the home page. The application is operated by a single individual, for their own use, to back up their own Google Drive. It is not offered to the public and has no users other than its owner.

Data accessed

Through the Google Drive API, and only after the owner explicitly grants access, the application may access:

  • The contents of files stored in the owner's Google Drive.
  • File and folder metadata (names, sizes, timestamps, checksums, sharing status).
  • Google Docs, Sheets and Slides, exported to standard formats.

The Google OAuth scopes requested are https://www.googleapis.com/auth/drive, https://www.googleapis.com/auth/docs and https://www.googleapis.com/auth/drive.metadata.readonly, as recommended by the rclone documentation.

How the data is used

  • Data is copied from Google Drive to storage owned and controlled by the owner (a local disk or another storage account of the owner), for backup purposes only.
  • OAuth tokens are stored locally in the owner's rclone configuration file on the owner's own computer.
  • No data is transmitted to any third party, and no data is used for advertising, profiling, analytics, or training of any kind.
  • The application has no server component: all processing happens on the owner's machine, and the only external service contacted is Google's API.

Data sharing

None. Data retrieved from Google Drive is never shared, sold, or disclosed to anyone.

Data retention and deletion

Backup copies are retained on the owner's storage for as long as the owner chooses. The owner can delete backups at any time, and can revoke the application's access to Google Drive at any time from Google account permissions. Revoking access immediately invalidates the stored OAuth tokens.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

These pages are static and hosted on GitHub Pages. They set no cookies and include no analytics or tracking. GitHub may collect standard server logs as described in the GitHub Privacy Statement.

Contact

Questions about this policy can be raised by opening an issue on the project repository.
